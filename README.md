# rPPG 심박·스트레스 측정 앱 (Android) — v2

전면 카메라로 얼굴 피부색의 미세한 변화를 분석해 심박수(BPM)와 스트레스 지수를 추정하고,
웨어러블 워치 심박과 같은 화면에서 비교합니다.

## 설치
[Releases](../../releases)에서 최신 `rppg-N.apk`를 받아 설치합니다(출처를 알 수 없는 앱 허용 필요).
`rppg` 브랜치에 푸시하면 GitHub Actions가 자동으로 APK를 빌드해 릴리스에 올립니다.
v2부터 고정 서명키를 써서 이후 버전은 덮어쓰기 설치됩니다(v1은 한 번 삭제 후 설치).

## 사용 흐름
1. 메뉴(⋮) → **기본 설정**: 나이·성별(필수), 키·몸무게, 측정 시간(30/60/120초) — 완료 전에는 측정 버튼 잠금
2. 메뉴 → **워치 연동**(선택): BLE 심박 기기 검색/선택 또는 Health Connect 권한
3. 메뉴 → **체질 진단**(선택): 12문항 사상체질 설문
4. 측정 시작 → rPPG BPM · 워치 BPM · 스트레스 카드 + 비교 그래프 → 종료 시 결과 요약

## 기능과 원리
| 기능 | 방법 |
|---|---|
| 심박 | ML Kit 얼굴 → 이마·양볼 ROI 평균 RGB → 30Hz 재샘플링 → POS → 0.7–3Hz 필터 → 스펙트럼 피크 |
| 스트레스 | 심박 ±0.6Hz 협대역 맥파의 영교차로 박동 검출 → RR 정제 → RMSSD·SDNN·Baevsky SI(√SI) → 0–100점. 박동 검출률 85% 미만이면 "신호 불충분" |
| 체질 | 사상체질 간이 설문 12문항 + BMI 가중 → 4체질 백분율. 심박 신호로 체질을 판별하지는 않음 |
| 워치 비교 | BLE Heart Rate Profile(0x180D, 실시간) 또는 Health Connect(갤럭시워치/삼성헬스 등, 동기화 지연) → 시점 매칭 평균 절대 차이 |

## 워치별 안내
- **가민/폴라/코로스, 가슴 스트랩**: 워치에서 '심박 브로드캐스트' 켜고 BLE로 연결
- **갤럭시워치**: 표준 BLE 심박 송출이 없어 Health Connect 사용(삼성헬스→Health Connect 심박 쓰기 허용). 워치에서 운동 모드를 켜면 데이터가 촘촘해짐. 실시간이 필요하면 워치에 심박 브로드캐스트 앱 설치 후 BLE 사용

## 한계
